LLM 가상 응시자 테스트

DeepSeek가 가상 응시자의 행동 특성에 따라 성향 문항과 게임 상황에 답합니다. 실제 지원자 데이터는 읽거나 저장하지 않습니다.

텍스트 상황 시뮬레이션입니다. 실제 게임 화면을 클릭하거나 시각·운동 능력을 측정하지 않습니다. 반응시간은 모델이 생성한 가상 값이며 LLM 호출 시간과 별도로 표시합니다. 결과는 채용 합격선이나 실제 사람의 능력을 검증하는 자료가 아닙니다.

선택한 제공자에 문항·가상 행동 특성을 전송하며 API 사용량이 발생합니다. 동일 시드는 상황을 재현하지만 LLM 응답의 재현성을 보장하지 않습니다.
